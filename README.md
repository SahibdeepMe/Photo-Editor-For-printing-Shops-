# 🖨️ QuickPrint Grid - Photo Editor for Printing Shops

An intuitive, lightweight web tool designed for print shops, cyber cafes, and studio owners to quickly arrange and print photos onto standard **A4 paper** in an optimized grid layout.

🔗 **Live Demo:** [Photo Editor For Printing Shops](https://sahibdeepme.github.io/Photo-Editor-For-printing-Shops-/)

---

## 🌟 Overview

Shopkeepers and printing operators often spend unnecessary time opening heavy graphic design software (Photoshop, CorelDRAW, Word) just to duplicate passport-size or custom-sized photos across an A4 sheet.

This project streamlines the workflow:
1. Upload customer photos.
2. Select desired grid density (pictures per page).
3. Adjust sizing/zoom.
4. Hit print (`Ctrl + P` / `Cmd + P`) with print-ready margins.

---

## ✨ Key Features

- **⚡ Instant Grid Formatting:** Automatically arranges photos into optimized rows and columns across standard A4 dimensions.
- **📄 Customizable Density:** Easily set the number of photos per sheet (e.g., 2, 4, 8, or passport-size grids).
- **🔍 Scaling & Fit Adjustments:** Scale or zoom images to fit cleanly without distorted aspect ratios.
- **🖨️ One-Click Print Ready:** Built-in print CSS rules hide UI panels and controls during printing, outputting only clean, crisp image sheets.
- **🔒 Client-Side & Private:** Images are processed directly within the user's browser—no photos are uploaded to any server or cloud storage.
- **💻 Zero Installation:** Runs entirely inside modern desktop or mobile browsers.

---

## 🚀 How to Use

1. Open the [Live Web Application](https://sahibdeepme.github.io/Photo-Editor-For-printing-Shops-/).
2. Click **Upload** to select an image from your device.
3. Configure your layout:
   - Select the number of **Pics Per Page**.
   - Adjust the image scaling percentage if needed.
4. Click **Print** (or press `Ctrl + P` / `Cmd + P`).
5. In the printer settings dialog:
   - Set paper size to **A4**.
   - Set margins to **None** or **Default**.
   - Confirm and print!

- **JavaScript (Vanilla):** DOM manipulation, Canvas/FileReader API for client-side image processing.
